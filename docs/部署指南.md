## 二、数据库与数据保存方式

### 2.1 用的是什么数据库

**PostgreSQL**（开源关系型数据库），通过 **Prisma ORM** 访问。

- 本地开发/预览：沙箱内运行的 PostgreSQL 18
- 正式上线：换成云端的 PostgreSQL 服务即可，**代码一行都不用改**，只需更换一个连接串（`DATABASE_URL`）

### 2.2 数据存在哪里（这点很关键）

| 数据类型 | 存放位置 | 说明 |
|---|---|---|
| 课堂、题目、选项 | 云端数据库 | 教师创建，所有设备可见 |
| 学员作答内容 | 云端数据库 | 学员提交后即写入云端 |
| 统计结果 | 实时计算 | 每次查看时从数据库现算，保证实时 |

**没有使用浏览器本地存储来保存业务数据。** 学员换手机、清理缓存，都不会丢失已提交到云端的答案。

浏览器本地仅保存两类"身份凭据"：
- `mhc_participant_id`：学员的匿名标识（用于识别"我答过这题"）
- `mhc_teacher_token_xxx`：教师的管理令牌

> 📌 **给教师的提示**：教师令牌存在本机浏览器里。所以**建议固定用办公室那台电脑创建和主持课堂**，并把这个页面的网址加入收藏夹。换台电脑就找不回原来的课堂了（课堂数据本身仍在云端，只是没有管理入口）。

### 2.3 数据表结构（4 张表）

| 表名 | 作用 | 主要字段 |
|---|---|---|
| `Classroom` | 课堂 | 课堂码、名称、教师令牌 |
| `Question` | 题目 | 类型、题干、状态（未开始/答题中/已结束） |
| `QuestionOption` | 选择题选项 | 选项标号 A/B/C/D、内容 |
| `Answer` | 学员作答 | 学员标识、昵称、选项、文字、关键词 |

学员标识 + 题目编号构成唯一约束，**同一学员对同一题重复提交会自动覆盖**，学员可以在教师结束答题前随时修改答案。

### 2.4 如何备份数据

方法一（最简单）：教师端每道题都有「导出本题结果（CSV）」按钮，可逐题导出 Excel 能打开的表格。

方法二（整库备份）：在服务器上执行
```bash
pg_dump "postgresql://用户:密码@主机:5432/数据库名" > backup.sql
```

## 三、发布为公网 HTTPS 网址（三种方案）

> 先说结论：**如果只是先试用，用方案 B；如果正式用于教学，用方案 A。**

### 方案 A：腾讯云 CloudBase（云开发）— 国内正式使用推荐 ⭐

**为什么推荐**：服务器在国内，手机扫码响应快；微信内打开体验好；自带 HTTPS 证书，不用自己配置。

**操作步骤**：

1. 打开 https://tcb.cloud.tencent.com/ ，用微信或手机号注册腾讯云账号
2. 完成**实名认证**（个人：身份证 + 人脸；单位：营业执照）——国内云服务商都强制要求，无法跳过
3. 创建一个云开发环境（按量计费或套餐）
4. 开通云托管服务，选择「Docker 镜像」部署
5. 在项目根目录打开命令行，执行：
   ```bash
   npm install -g @cloudbase/cli
   tcb login
   tcb deploy
   ```
6. 部署完成后平台会给出一个 `https://xxx.tcloudbaseapp.com` 形式的网址，这个就是公网 HTTPS 网址

7. **配置数据库**（只需一次）：在云开发控制台开通 PostgreSQL 数据库，复制连接串，填入云托管服务的环境变量 `DATABASE_URL`

**费用**：云开发有免费额度（含一定的数据库存储和访问量）。一个几十人课堂的场景，通常每月几元到几十元。超出免费额度才计费。

**备案情况**：
- 使用平台提供的默认域名（`*.tcloudbaseapp.com`）→ **不需要备案**
- 想用你们学校的域名（如 `classroom.your-university.edu.cn`）→ 需要 ICP 备案（学校通常已有备案，可添加二级域名，走学校信息中心流程）

---

### 方案 B：Render + Neon — 免备案，适合先试用 ⭐

**为什么适合试用**：不需要实名认证、不需要备案、不需要信用卡。注册 GitHub 账号即可。

**缺点**：服务器在国外，国内访问速度较慢，微信内打开可能偏慢。

**操作步骤**：

1. **准备代码**：把整个项目文件夹上传到 GitHub（新建仓库 → 上传文件）
   > 需要先把 `backend/.env` 删掉或加入 `.gitignore`，不要把数据库密码传上去

2. **创建数据库**（免费）：
   - 打开 https://neon.tech/ ，用 GitHub 登录
   - 创建一个项目，复制它给的 `postgresql://...` 连接串

3. **部署网站**（免费）：
   - 打开 https://render.com/ ，用 GitHub 登录
   - 点「New」→「Web Service」→ 选择你刚上传的仓库
   - Runtime 选 `Docker`，Region 选 `Singapore`
   - 在环境变量里添加：`DATABASE_URL` = 刚才复制的连接串
   - 点「Create Web Service」，等待几分钟

4. 部署完成后会得到 `https://medical-humanities-xxx.onrender.com` 这样的网址

**费用**：免费计划可用，但**闲置 15 分钟后会自动休眠**，下次访问需要等约 30 秒唤醒。正式上课建议升级到付费计划（约 $7/月）。

**备案情况**：服务器在境外，**完全不需要备案**。

---

### 方案 C：自己的服务器 / 校园机房

如果学校提供服务器或虚拟机：

```bash
# 1. 安装 Docker（Ubuntu）
curl -fsSL https://get.docker.com | sh

# 2. 上传项目后，在项目根目录执行
docker build -t mhc .
docker run -d -p 80:3000 \
  -e DATABASE_URL="postgresql://用户:密码@主机:5432/数据库名" \
  -e NODE_ENV=production \
  --name mhc mhc
```

访问 `http://服务器IP` 即可。若需 HTTPS，需要申请证书并配置反向代理（Nginx），这一步建议请学校信息中心协助。

**备案情况**：使用域名在中国大陆境内服务器上提供服务，**需要 ICP 备案**。仅用 IP 地址访问通常也要求备案，建议直接走学校备案流程。

## 四、关于实名认证、备案、付费 — 明确回答

### 实名认证

| 平台 | 是否需要 |
|---|---|
| 腾讯云 / 阿里云 / 华为云等国内平台 | **必须**，且强制 |
| Render / Neon / Railway 等海外平台 | 不需要（用 GitHub/邮箱登录即可） |

### ICP 备案

记住一条判断标准：**用自定义域名访问中国大陆境内的服务器，才需要备案。**

| 场景 | 是否需要备案 |
|---|---|
| 腾讯云 CloudBase 默认域名 | ❌ 不需要 |
| Render（境外服务器） | ❌ 不需要 |
| 自己的域名 + 腾讯云/阿里云服务器 | ✅ 需要 |
| 学校域名（已备案）+ 二级域名 | ✅ 需要向学校信息中心报备添加 |

备案本身免费，但流程通常需 10–20 个工作日，需通过接入商提交。

### 付费

| 平台 | 免费额度 | 付费水平 |
|---|---|---|
| 腾讯云 CloudBase | 有免费额度 | 超出后约几十元/月 |
| Render | 免费计划（会休眠） | 约 $7/月起 |
| Neon | 免费计划 | 约 $19/月起（超出后） |
| 自建服务器 | — | 约 50–200 元/月 |

**给学校的建议**：先按方案 A 用免费额度跑通一次真实课堂，确认效果后再决定是否升级套餐或走学校采购流程。

## 五、上线后的使用流程

### 教师端（上课前 5 分钟）

1. 打开网站首页 → 点「我是教师」
2. 输入课堂名称（如「医学伦理学·第5讲」）→ 点「创建课堂」
3. 进入控制台后，屏幕上会显示**课堂码**和**二维码**
4. 点「放大投屏」，让学员扫码
5. 发布题目：选择题型 → 填题干 → 填选项 → 点「发布题目」
6. 点「开始答题」，学员即可作答
7. 实时查看结果，讲评完毕后点「结束答题」
8. 需要存档就点「导出本题结果（CSV）」

### 学员端

1. 用手机扫屏幕上的二维码（或打开网址后点「我是学员」输入课堂码）
2. 填昵称（选填，不填就是匿名）
3. 等教师发布题目，页面会自动显示
4. 作答 → 提交 → 看到「已提交」
5. 在教师结束答题前，可以点「修改我的答案」

## 六、常见问题

**Q：关掉开发电脑后网站还能用吗？**
A：现在这个预览环境关掉就访问不了了。**完成第三节的部署后**，网站运行在云服务器上，跟你的电脑无关，随时可访问。

**Q：学员需要安装 APP 或注册吗？**
A：都不需要。扫码打开网页，填个昵称（也可以不填）就能答题。

**Q：能同时多少人答题？**
A：按每 2 秒刷新一次的节奏，几十人到一两百人都没有压力。更大规模可以做优化。

**Q：学员的答案会泄露吗？**
A：学员端只能看到自己的作答，看不到别人的。只有教师端能看到汇总结果。

**Q：课堂能重复使用吗？**
A：可以。同一个课堂码可以反复用于不同班级，历史作答会一直累计在同一道题下。如果想分开统计，创建新的课堂即可。

**Q：数据会丢吗？**
A：数据在云端数据库里，不会因为关机或换设备丢失。建议重要课堂结束后用 CSV 导出留档。

## 七、给技术维护人员的信息

### 技术栈

- 前端：React 19 + TypeScript + Vite 7 + Tailwind CSS 4 + Recharts + ECharts(词云) + qrcode
- 后端：Node.js 22 + Express 4 + TypeScript + Prisma 6 + PostgreSQL
- 实时：HTTP 轮询（2 秒间隔），无 WebSocket 依赖，便于云平台部署

### 目录结构

```
/workspace
├── backend/          # 后端服务（端口 3000）
│   ├── prisma/schema.prisma
│   └── src/
├── frontend/         # 前端（开发端口 5173，生产打包为 dist）
│   └── src/
├── Dockerfile        # 生产镜像
├── render.yaml       # Render 部署蓝图
└── docs/部署指南.md
```

### 环境变量

| 变量 | 必填 | 说明 |
|---|---|---|
| `DATABASE_URL` | ✅ | PostgreSQL 连接串 |
| `NODE_ENV` | ✅ | 开发环境 `development`，生产 `production` |
| `PORT` | ❌ | 默认 3000 |
| `CORS_ORIGIN` | ❌ | 默认 `*`，生产建议填实际域名 |

### 接口清单

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| POST | `/api/classrooms` | 公开 | 创建课堂 |
| POST | `/api/classrooms/join` | 公开 | 学员凭码加入 |
| GET | `/api/classrooms/:id` | 教师 | 课堂详情 |
| GET | `/api/classrooms/:id/active` | 公开 | 学员端获取当前题目 |
| POST | `/api/classrooms/:id/questions` | 教师 | 发布题目 |
| POST | `/api/questions/:id/open` | 教师 | 开始答题 |
| POST | `/api/questions/:id/close` | 教师 | 结束答题 |
| DELETE | `/api/questions/:id` | 教师 | 删除题目 |
| GET | `/api/questions/:id/stats` | 教师 | 实时统计 |
| POST | `/api/questions/:id/answers` | 公开 | 提交答案 |

教师端接口通过请求头 `x-teacher-token` 鉴权。

### 本地开发

```bash
cd backend && pnpm install && pnpm dev     # 端口 3000
cd frontend && pnpm install && pnpm dev    # 端口 5173
```

数据库连接串写在 `backend/.env` 中（该文件不应提交到代码仓库）。
